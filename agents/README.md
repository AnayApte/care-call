# Agent briefs

One file per person. Each file is that person's brief for their coding agent: role, folders, first tasks, and how to start.

How to start your agent (Claude Code, Codex, whatever you use), from the repo root, on your own branch:

> Read `CLAUDE.md`, then `shared/contract.md` in full, then `agents/<your-name>.md`. You are working for <your-name>. Do the "First tasks" list in order. Only edit your own folders. Update `shared/status/<your-name>.md` and `shared/changelog/<your-name>.md` after each chunk of work. Push to my branch on the hour.

Rules that matter most (the full list is in `CLAUDE.md`):
- Only edit your own folders.
- Never edit `shared/contract.md` or fixtures. Put requests in `shared/CONTRACT_REQUESTS.md`.
- Push every hour on the hour. Pull `main` before you start each block.
- Golden path first, layers second.
